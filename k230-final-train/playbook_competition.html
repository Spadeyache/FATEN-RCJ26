Competition Playbook 🏁

K230D YOLOv8n ・ k230-final-train フォルダ内で実行 ・ venv 不要(Docker)

準備

1
Docker Desktop を起動（1〜3分）
2
アノテーション済みエクスポート（images/ labels/ classes.txt）を raw_export/ に入れる。新しい写真を追加する時もここに置くだけ（古いのと自動で結合）。
3
PTQ校正画像（推奨）：当日 K230D カメラで撮った写真を datasets/<Name>/calibration/ に入れる。16〜30枚、各クラス(Dead/Live/Point)・距離・明るさをばらけさせる。ラベル不要。自動で校正に使われ、学習には影響しない。無ければ val 画像で代用。

実行（これ1行）

.\competition_run.ps1 -Name victim_v2 -Epochs 100
データ整理 → 学習 → ONNX → kmodel(ベスト設定) → レポート → 配布バンドル、まで全自動（約20分）。

分けて回すなら

.\add_data.ps1 -Name victim_v2raw_export/ をまとめて train/val に分割（クラス一致を確認）
.\train_model.ps1 -Name victim_v2YOLOv8n 学習 + ONNX 書き出し
.\convert_model.ps1 -Name victim_v2ONNX → kmodel（ベスト）+ レポート + deploy

よく使うオプション

-Epochs 150学習エポックを増やす（精度↑、時間↑）
-SkipTrain学習し直さず、既存モデルで変換だけ
-Search量子化5設定を総当りして最良を選ぶ（約60分）

できるもの

deploy/best.kmodel ＝ 配布する最良モデル
report.html ＝ 学習 mAP・量子化結果のレポート
deploy/ ＝ best.kmodel + labels.txt + deploy_config.json + deploy_canmv_yolov8.py

実機へ

1
deploy/ の4ファイルを K230D の SD カード /data/k230-final-train/ にコピー（+ test.jpg も）
2
CanMV REPL で：import deploy_canmv_yolov8; deploy_canmv_yolov8.detection()
⚠ kmodel は nncase 2.11 製。実機の CanMV ランタイムが 2.11 互換か確認してから本番投入すること。
