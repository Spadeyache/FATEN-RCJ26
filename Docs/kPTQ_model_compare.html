K230D Quantization — Overview of Methods
2026 / 78 GTs / 50 val

Every quantized AnchorBaseDet (can3_5_s) variant we tried failed structurally — the classifier head saturates under uint8 PTQ. Pivoting to YOLOv8n (SiLU, no SE, DFL head) restored deployable accuracy. The PTQ numbers that previously read "recall = 0" were artifacts of the PC-side nncase 2.9.0 Simulator mis-executing the YOLOv8 DFL head; once the host compiler/sim package was upgraded to nncase 2.11.0 (the on-device nncase_runtime in CanMV was not touched), the same kmodel files reveal their real performance, summarised below.

DEPLOY — deployable PTQ winner: matches float on geometry AND single-best ranking.
Solid PTQ — accurate boxes but score saturation; deployable with care if you only need "is something there".
Partial — improves on the broken baseline but unreliable for single-best wire protocols.
Broken — recall ≈ 0 on single-best, or output collapse.
Float reference — accuracy ceiling; not deployable for speed reasons.

r@0.05, r@0.4: recall at IoU ≥ 0.5 with score thresholds 0.05 and 0.40. avg_bsi = mean IoU of the highest-scoring same-class box — the metric the single-best UART protocol actually depends on.
