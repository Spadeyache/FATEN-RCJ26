Teensy — STS-imuMerge main controller: drive, sensing, state machine

StateMachine namespace StateMachine

void init()

Boots the FSM in LINE_FOLLOW. Call once from setup().

void tick()

Runs onEnter() once on a transition, then the active state's update(). Called every main-loop iteration.

void transitionTo(RobotState next)

Queues a state change; applied on the next tick(). States: LINE_FOLLOW / LINE_OBSTACLE / LINE_GAP / STALLED_RED / EVAC_ENTRY / EVAC_SEARCH_DEPLOY / EVAC_EXIT.

RobotState current()

The currently active state.

State handlers LINE_* / EVAC_* namespaces

LINE_Follow::onEnter() / update()

Default driving. Dispatches on the XIAO feature byte: bumper→obstacle, U-turn, red→stall, silver→evac entry; otherwise runs the line PID.

LINE_Obstacle::onEnter() / update()

Front bumper hit: drive a fixed arc around the obstacle, then wait for the XIAO to re-acquire the black line.

LINE_Gap::onEnter() / update()

Line-gap traversal (gap/intersection crossing helper). Steers on the XIAO line-angle output.

EVAC_Entry::onEnter() / update()

Fixed entry sequence into the evacuation zone (reset VictimManager, attach servos, drive in), then hands to search-deploy.

EVAC_SearchDeploy::onEnter() / update()

The 2-minute collect↔deploy loop: spin-search victims, grab via VictimManager, deploy live at the green corner / dead at the red corner.

EVAC_Exit::onEnter() / update()

Leave the zone: switch the XIAO back to line mode and return to LINE_FOLLOW.

VictimManager namespace VictimManager

void reset() / void clearAll()

Empty both arms — reset() at evac start, clearAll() after a deploy.

uint8_t count() / liveHeld() / deadHeld()

How many balls are currently held, total and split by type.

bool full()

Both arms at capacity (left 2 + right 1).

bool acceptsType(uint8_t type)

Should the search keep chasing this victim type? DEAD only if none held and the right arm is free; ALIVE whenever any arm has space. Used to filter detections.

bool readyToDeploy()

True once ≥2 live balls are held — the trigger to break off and deploy green.

bool tryGrab(uint8_t type)

Pick an arm, run the align + grab + self-confirm, and book the ball only if confirmed captured. Returns false on a miss (nothing counted).

void releaseLive() / void releaseDead()

Drop balls by type at the corner — live from the left arm (+right overflow), dead from the right.

Drive namespace Actions::Drive

void init()

Brings up the STS servo bus and starts the 9 ms control-timer ISR that pushes wheel gains.

void motor(float L, float R, bool imuComp=false)

Set both drive sides (±MAX_MOTOR_SPEED, clamped). The ISR mirrors L→front/back-left, R→front/back-right. imuComp adds slope compensation.

void stop()

motor(0,0).

void spinDecay(float power, uint32_t durationMs)

Blocking in-place spin that ramps from |power| down to 35 over the duration. Used for search/deploy sweeps.

void motorRaw(float fl, float fr, float bl, float br)

Bench-test only: drive each wheel independently (no L/R mirror, no IMU comp).

void runLinePID()

One tick of the slope-aware line-follow PID off XiaoDecode::lineError(). Called every loop in LINE_FOLLOW.

float frontLeftGain() / frontRightGain() / backLeftGain() / backRightGain()

Last commanded per-wheel gains — read by Mapping for the unicycle motion model.

Arm namespace Actions::Arm

void init()

Attach the two grippers + KRS lift, close the grippers, park the lift.

void grabLeft(bool closed, bool blocking=true)

Open/close the left (alive/silver) gripper. Blocking ramps the servo smoothly.

void grabRight(bool closed, bool blocking=true)

Open/close the right (dead/black) gripper.

void store()

Move the ball in the left gripper into the bucket so the gripper is free for a second one (left = 2, LIFO). TODO macro

void releaseLeft() / releaseRight() / releaseStore()

Drop a single ball: the left gripper / the right gripper / the left bucket. releaseStore is the bucket primitive. store/releaseStore TODO

void releaseBothLeft()

Drop the left gripper ball then the bucket ball (LIFO order).

void releaseAll()

Blocking: drop every held ball.

void lift(int us)

Raw KRS lift pulse width (microseconds, clamped). Holds via PWM refresh.

void liftDown() / liftCarry() / liftPark()

Named lift poses — reach-to-grab / carry-up / parked.

void attachServos() / detachServos()

Manually (re)engage or silence the hobby servos inside long sequences.

Turn / Forward / SilverAlign namespace Actions

Turn::turn(float angle_deg, float speed=65)

Blocking in-place spin. +angle = right, −angle = left; duration is speed-scaled from one calibration constant.

Forward::forward(float speed, float dist_mm, bool useIMU=false, bool pumpComms=false)

Blocking straight drive of a calibrated distance (negative speed reverses). useIMU holds heading; pumpComms services the XIAO link during the move.

bool SilverAlign::align()

Spin to square the robot to the evac silver tape (drives reported tape tilt to ~0). Returns true on convergence, false on timeout.

XiaoDecode namespace Processing::XiaoDecode

void tick(bool instantRun=false)

Read the XIAO register cache and feed the feature byte through CommandFilter (~50 Hz). Call every loop.

uint8_t command()

The confirmed FEAT_* event (FEAT_NONE if none) — the debounced line-follow signal the state machine acts on.

float lineError()

Line position error 0..254 (127 = centred), fed into the drive PID.

float gapAngle() / gapFineAngle() / uint8_t gapLineY()

Gap-crossing geometry: rough slope, precise two-row angle, and the point's Y — used by LINE_GAP.

bool commitFlag() / tightSlowFlag()

XIAO is mid green-turn commit / the turn target is low in frame (drive slower).

bool gapAnyPointFlag() / gapBothRowsFlag() / gapBottomLineFlag() / gapFineAngleFlag()

Per-frame gap detector flags (point seen, two rows, bottom edge, fine angle valid).

bool obstacleSeeLine() / float obstacleAngle()

Obstacle-reacquire mode: line back in view + its tilt.

bool silverSeen() / float silverAlignAngle()

Evac tape seen + its angle, used by SilverAlign.

void setMode(XiaoMode m)

Tell the XIAO which vision mode to run (LINE / SEARCH_LINE / NOGI / LINE_ANGLE / OBSTACLE / SILVER_ALIGN).

void clearFilter() / void setCommand(uint8_t c)

Reset the debounce votes / force the current command (used during scripted manoeuvres).

K230Decode namespace Processing::K230Decode

void tick()

Drain the K230 serial and parse the latest detection frame. (Pair long blocks with drainDelay so the buffer never overflows.)

void drainDelay(uint32_t ms)

Block for ms while continuously ticking, so the next read sees the newest frame. Use instead of delay() near K230 reads.

const Box* boxes() / uint8_t boxCount() / uint32_t lastPacketMs()

The most recent frame's detection boxes and its timestamp.

bool isVictimClass(uint8_t cls) / bool isPointClass(uint8_t cls)

Class test: Dead/Alive ball vs. evac-point corner.

bool checkVictim() / bool checkPoint()

Scan the latest frame for the best victim / corner and load goalPOS / pointPOS.

int16_t largestCenterX(uint8_t cls)

Centre-X (px) of the largest box of a class, or −1. Used to vision-align a grab.

int16_t largestHeight(uint8_t cls)

Tallest box height of a class, or −1. Used to confirm a grab (ball gone = captured).

int16_t dominantClass()

Class of the largest box in the frame — in POINTS mode this is the corner colour.

void setModel(Model m)

Command the K230 to load the victims model (Dead/Live/Point) or the points model (Green/Red).

void setRunning(bool) / bool isRunning()

Detect/idle run flag for the K230.

CommandFilter & Pose Processing

CommandFilter::update(uint8_t rawCmd) -> uint8_t

Majority-vote ring buffer over the raw XIAO feature byte; returns a FEAT_* code once it passes its threshold within the window. Vote totals are exposed for debug.

CommandFilter::clear()

Wipe the vote window (e.g. after acting on a command).

poseInit(Pose&, x, y, theta, ...)

Seed the 3-state (x,y,θ) EKF and its covariance.

posePredict(Pose&, v, omega, dt)

Integrate the motor-commanded velocity/turn-rate forward one step.

poseUpdateYaw(Pose&, yaw) / poseUpdateWall(Pose&, angle, d)

Correct the pose from the IMU yaw / (phase 2) a ToF wall snap.

wrapAngle(float) / poseInflateCovariance(...)

Wrap to ±π / bump uncertainty after an un-modelled move.

void tick()

Predict from motor commands + correct with IMU yaw each loop.

const Pose& pose()

Current (x,y,θ) estimate.

void persist() / void handleSerial(char c)

Sensors namespace Sensors

IMU::init() / tick() / getPitch() / getRoll() / getYaw()

MPU-6050 + Madgwick. tick() is internally throttled; getters return degrees (yaw wrapped ±180).

Touch::init() / tick() / front() / conduct0() / conduct1()

Front bumper + two conductivity probes. Getters return true = active.

ToF::init() / tick() / sensor(i) / count() / printFL()

VL53L7CX array; tick() refreshes tofFL[8][8] front-left distances when a fresh frame is ready.

XIAO_link::init() / tick() / get(reg) / send(reg, value)

Raw register transport to the XIAO. tick() drains RX into the cache; get/send read/write [255,reg,value].

K230_link::init() / tick() / readByte() / setCommand(cmd)

Raw byte transport to the K230; tick() buffers RX and re-sends the run/idle command.

Drivers low-level device classes

yacheSTS::power(lf, rf, lb, rb) / stop() / setWheelMode() / begin(serial, baud)

Feetech STS 4-wheel servo bus (SyncWrite). power() takes ±100 per wheel; right-side sign handled internally.

yacheVL53L7CX::begin() / dataReady() / getRanges(mm, status) / zoneBearing(i) / isValid(status, mm)

VL53L7CX multizone ToF wrapper + mount transform (sensor→robot frame). isValid() gates good readings.

yacheMPU6050::begin() / update() / calibrate() / getPitch/Roll/Yaw() / load/saveOffsetsFromEEPROM()

MPU-6050 + Madgwick (no DMP); offsets persist to EEPROM.

YacheEncodedSerial::update() / get(id) / send(id, value)

3-byte [255,id,value] register protocol over UART (shared Teensy↔XIAO). Values clamped 0..254.

YacheK230D::update() / box(i) / boxCount() / hasFreshFrame(ms) / sendCommand(cmd)

K230 box-list parser: [AA 55 N (10-byte boxes) XOR]. update() is non-blocking; sendCommand() controls run/idle + model.

XIAO ESP32-S3 — XIAOdev camera vision co-processor: line + colour detection

Vision modes one per XIAO mode; run() per camera frame

modeLineFollowRun(fb, teensy) / modeLineFollowReset()

Mode 0. Scan the line row, send line error (COM) + the highest-priority feature (green/red/silver/U-turn) to the Teensy.

modeSearchLineRun(fb, teensy)

Mode 1. Look for tape in a region; report silver tape or the black return line (black wins). Used after a U-turn / around obstacles.

modeNoGIRun(fb, teensy)

Mode 2. Far-field black-pixel count across rows; flags a no-green intersection ahead.

modeLineAngleRun(fb, teensy)

Mode 3. Gap-crossing helper: report the line slope, a precise fine angle, and point flags so the Teensy can drive straight across a gap.

modeObstacleRun(fb, teensy)

Mode 4. After going around an obstacle, confirm the line is back in the top arc and report its tilt.

modeSilverAlignRun(fb, teensy)

Mode 5. At the evac entrance/exit, classify the big tape as silver or black and report its angle for perpendicular alignment.

LineCount crossing detection & tracking

lc_detectCrossings(fb, LineCounts& out)

Walk the ROI border as a 1-D loop and list every black crossing (the raw input to all line logic).

lc_updateIn(lc) -> LineClass

Track the "in" line (the one the robot is on) frame-to-frame and split the rest into branch "outs".

lc_trackPoint(prevPos, lc) / lc_lowestPixel(lc) / lc_resetTracking()

Nearest-with-gating tracker / base case (nearest-to-robot crossing) / forget the tracked point on a mode change.

lc_commitStart(left) / lc_commitUpdate(...) / lc_commitActive() / lc_commitLocked() / lc_commitProgress() / lc_commitClear()

Green-turn commit: lock the steering target onto the chosen branch and follow it through the intersection until the line straightens.

lc_focusedOut(lc, inIndex) / lc_slopeError(...) / lc_inOutAngleDeg(...)

Pick the steering target out-point, compute the 0..254 line error, and the in→out angle (to know when a turn is done).

GreenFilter green marker confirmation

uint8_t gf_update(uint8_t raw)

Rolling-window vote over per-frame green observations; returns a confirmed code (0 none, 1 U-turn, 2 left, 3 right).

void gf_reset()

Clear the vote window after acting on a green.

rgb565To888() / rgb888_to_hsv() / rgbToGray() / rgb888Calibration() / unpackRGB565() / sampleRawRgb()

Low-level pixel conversion + per-camera colour calibration helpers.
